# CyberWithSteve — Home Lab Basics: Student Resources

Official companion files for the **CyberWithSteve Home Lab Basics** workbook: exercise files, templates and diagrams you need to complete the labs.

> **Sunshine Dental is a fictional company.** All names, systems and networks in these files are for training only.

## How to download a file

1. Open the folder for your module and lab, for example `module-01/lab-1.4/`.
2. Click the file you need.
3. Click **Download raw file** (the download icon above the file's contents).
4. Save it to the matching folder in your `CyberWithSteve-Labs` directory.

Download exercise files **only from this repository**. Files from anywhere else may have been modified.

## Contents

| Folder | What it contains |
| --- | --- |
| `module-01/lab-1.4/` | `SD-0007-network-diagram.drawio`: the diagram for the Lab 1.4 break-fix challenge. **It contains deliberate mistakes.** |
| `resources/templates/` | Lab notes, portfolio page and inventory templates used throughout the workbook |

More folders are added as each module is released.

## What is not here

This repository holds **student files only**. It does not contain the workbook chapters, answer keys or completed solutions. If you find a solution file here, please report it.

## Found a problem?

Open an **Issue** in this repository with the lab number, what you expected and what happened. Reports from learners are how the workbook gets better.
